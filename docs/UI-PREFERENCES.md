# UI Preference Profile

This file records Marc's durable visual preferences. Keep it short and update it
only when direct feedback establishes or reverses a preference.

## Current direction

- Approved by Marc: the centered A4-style web résumé introduced in July 2026.
- GitHub-dark is the default theme; light mode remains available.
- A4-inspired document composition with compact components, short section gaps,
  and strong alignment.
- Balanced information density on the homepage: fill the document with essential
  portfolio evidence while deeper content remains on focused secondary pages.
- Resume-like structure presented as an interactive website, not a copied résumé
  document or oversized landing page.
- Distinctive and editorial rather than a common portfolio template.
- Ladder/timeline treatment for progression and experience.
- A visible profile picture is required.
- Motion is minimal, snappy, smooth, and reduced-motion safe.
- Links expose only important information, with “more” paths to deeper pages.
- SNUHI must not appear unless Marc explicitly requests it later.

## Avoid

- Dense dashboards, disconnected cards, or large empty landing-page bands.
- Repeating the same biography, metrics, and links in multiple sections.
- Oversized hero copy that pushes useful content below the fold.
- Decorative animation, strong glass effects, and excessive gradients.
- Long technology lists on the homepage.

## Feedback loop

For a substantial redesign, compare the result against this profile. If the
direction is still ambiguous, present two or three clearly different options
and ask Marc to choose before performing a broad rewrite.
